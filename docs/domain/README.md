## Key concepts

Store things like:

- core business rules
- invariants that must remain true
- glossary and terminology
- integration contracts with external systems

## Standard

Only put facts here that humans endorse as true enough to rely on.

If a rule is still being tested or debated, keep it in a temporary plan until it is ready to graduate.
