# Runbooks
Last edited: 2026-05-21

Use this folder for repeatable operational procedures.

## Key concepts

Examples include:

- deploys
- rollbacks
- incident response
- local environment recovery
- data repair steps
- retrofit and migration procedures
- validation checklists someone else can execute

## Usage

A runbook should be executable by someone who was not present for the original discussion.
