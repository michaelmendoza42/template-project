# Docs
Last edited: 2026-04-30

This directory holds canonical project documentation.

## Folders

- `adr/` — architecture decisions that became real
- `domain/` — business rules, invariants, contracts, and terminology
- `runbooks/` — repeatable operational procedures
- `special/` — project-specific policy, exceptions, and unusual repo knowledge
- `templates/` — copy/paste starters for docs that follow the repo schema

## Rule of thumb

If a fact matters to correctness, onboarding, architecture, safety, or repeatable operations, it belongs somewhere under `docs/` or in `AGENTS.md`.

If a note is still temporary, keep it in `plans/active/` or `tasks/` until it is ready to be promoted.
