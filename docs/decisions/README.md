# Decisions
Last edited: 2026-05-20
Status: Active
Scope: Consequential tradeoff records that should stay sparse
Related files: `../templates/decision.md`, `../product/README.md`, `../system/README.md`

Use this folder only when a durable record of alternatives and rationale will matter later.

## Key concepts

A decision record is warranted when all of these are true:

- there were real alternatives
- the choice constrains future work
- future maintainers will need the rationale, not just the outcome

## Standard

Do not use this folder for ordinary behavior specs, routine implementation notes, or temporary design thoughts.

Many durable docs should live in `../product/`, `../system/`, or `../standards/` instead.
